# 技術ドキュメントのハウススタイル (英語語混在 / bilingual)

AI 臭辞書 (`ai-japanese-patterns.md`) とは別軸。**技術ドキュメントで、地の文に既に
英語の固有名詞やコード識別子 (製品名・型名・API 名) が混ざっている場合に適用する**
用語・表記の統一ルール。一般の日本語記事・非技術文には適用しない (カタカナが自然な
語をむやみに英語化しない)。

適用の見極め: 対象内に `RequestContext` / `WorkStatus` / `StoreApp` のようなコード・
製品名が既に英語で出てくる、コードブロックがある、英語セクションがある — こうした
「bilingual な技術文」なら本ファイルも回す。純日本語の読み物なら回さない。

---

## 1. 技術借用語はカタカナではなく英語表記

英語由来の技術借用語は、カタカナではなく **英語 (先頭大文字)** で書く。

| カタカナ | 英語 | | カタカナ | 英語 |
|---|---|---|---|---|
| ポーリング | Polling | | オプション | Option |
| ステータス | Status | | トリガー | Trigger |
| データ | Data | | パターン | Pattern |
| ページ | Page | | エンティティ | Entity |
| サーバー | Server | | フィールド | Field |
| クライアント | Client | | インデックス | Index |
| システム | System | | タイムアウト | Timeout |
| リクエスト | Request | | ダイアログ | Dialog |
| リポジトリ | Repository | | プリセット | Preset |
| セッション | Session | | パッケージ | Package |
| イベント | Event | | バージョン | Version |
| コメント | Comment | | レベル | Level |
| タスク | Task | | レビュー | Review |
| フック | Hook | | ケース | Case |

- **製品名・システム名・状態名・型名は英語のまま**: Cockpit / StoreApp / Dashboard /
  OPM / WorkStatus / RequestContext / OperatorTask / Teleop など。
- **役割・登場人物も、ドキュメントの慣習が英語ならそれに合わせる**: Operator / Robot /
  Operation Team / Robot Team。
- **表記細則**: 先頭大文字 (`Operator` であって `operator` ではない)。ただしコード
  識別子・指標ラベルの内部は原文どおり詰める (`Operator応答率` のように)。
- **英語化しない例外**:
  - 日本語に定着し、英語だと硬い/意味がずれる語 — 例「運用チーム」(組織一般。
    `Operation Team` という固有の呼称とは別概念なら日本語のまま)。
  - 動詞的に使うと英語が座らない語は日本語の動詞へ — 「スタックする」→「詰まる」、
    「デッドロック」も文脈により「行き詰まり」。名詞なら英語 (`Deadlock`) でよい。
  - `English 語幹 + 日本語語尾` で慣用化しているもの — 「Restockモード」「テレオペ」。
- **迷ったら**: 同じ語がドキュメント内で既に英語で使われていれば、それに合わせて
  表記ゆれをなくす。

---

## 2. 英字と日本語の境界に半角スペースを入れない

日本語の地の文では、英単語とかな・漢字の境界にある半角スペースを詰める。

- **詰める**: 「StoreApp から」→「StoreAppから」 /「WorkStatus 遷移」→「WorkStatus遷移」/
  「DB 負荷」→「DB負荷」/「push 化」→「push化」/「Restock モード」→「Restockモード」。
- **残す (詰めない)**:
  - 英単語どうしの間 — `Happy Path` / `Operation Team` / `Technical Deep Dive`。
  - 数字 + 助数詞 — 「37 件/月」「5 秒」「2 点」(英「単語」ではないので対象外)。
  - コード・式の英語式スペース — `OperationMode = Restocking`。
  - 英文セクション全体 — 英語で書かれた本文はそのまま (英文中に `案2` `論点N` が
    出てきても、英文としての空白は保持する)。
- **機械的な規則 (正規表現)**: 「CJK 文字 + 半角空白 + 英字」および
  「英字 + 半角空白 + CJK 文字」の空白**のみ**除去。英字側は `[A-Za-z]` に限定して
  数字を含めない (助数詞前の空白を壊さないため)。

---

## 3. 図 (Mermaid など) の中の文言も同じ規則

図に埋め込んだラベル・Note も 1・2 と同じ表記に揃える。画像化している場合は、
**ソース (CDATA / .mmd) を直したら図を再生成して貼り直す** — テキストだけ直して
画像が古いままにならないよう注意する。

---

## 4. 適用手順 (安全のため)

1. 対象が bilingual な技術文かを見極める (上の「適用の見極め」)。
2. カタカナ借用語 → 英語 (表 1)。ただし置換前に **品詞と用法を確認** する
   (`ai-japanese-patterns.md` の運用ルール参照。「〜とセットで」を `Set` にしない等)。
3. 境界スペース除去 (規則 2)。
4. 図があれば同じ変換を図ソースにも適用し、再生成。
5. 変換後に「英字↔日本語の境界スペース」「表記ゆれ」が残っていないか grep で再確認。
